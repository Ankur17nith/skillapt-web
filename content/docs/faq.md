# Frequently asked questions

Common questions about skillpm, security, and runtime compatibility.

## What is an AI agent skill?

A skill is a portable package of instructions, tools, and context that gives an AI agent a specific capability.

## Are skills safe to install?

Package pages show their source repository, publisher identity, and requested permissions before installation. Automated scanning runs on every registry submission.

## Can I publish my own skill?

Yes! Add a SKILL.md file to a public repository and submit it for review on the submit page.
